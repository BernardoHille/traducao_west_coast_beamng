# Projeto de Tradução das Placas - West Coast USA (BeamNG.drive)

Este diretório contém todas as texturas de placas, letreiros, outdoors e sinalizações do mapa **West Coast, USA** do BeamNG.drive.

Para sua comodidade:
- **`.png`**: Versão de alta resolução pronta para abrir e editar em qualquer editor (Photoshop, Paint.NET, GIMP, Canva, etc.).
- **`.dds`**: Arquivo de textura original do BeamNG com compressão nativa (BC7 / DXT).

## Como Criar o Mod de Tradução no BeamNG

Para aplicar as texturas traduzidas sem alterar os arquivos originais do jogo:

1. Abra a pasta de usuário do BeamNG: `C:\Users\Desktop\AppData\Local\BeamNG\BeamNG.drive\current\mods\unpacked\meu_mod_traducao\`
2. Crie as subpastas mantendo exatamente o caminho virtual de cada textura substituída, por exemplo:
   - Para placas de trânsito (`t_roadsigns_b.color.dds`):
     `mods/unpacked/meu_mod_traducao/assets/materials/signage/roadsigns/t_roadsigns_b.color.dds`
   - Para placas comerciais (`clutter_commercial_b.color.dds`):
     `mods/unpacked/meu_mod_traducao/levels/west_coast_usa/art/shapes/buildings/clutter_commercial_b.color.dds`
   - Para postos de gasolina (`t_eca_genericsigns_b.color.dds`):
     `mods/unpacked/meu_mod_traducao/assets/materials/billboard_label/eca_genericsigns/t_eca_genericsigns_b.color.dds`
3. Salve suas imagens editadas como DDS (formato **BC7** com mipmaps gerados) ou como PNG (se for usar substituição de material).
4. Inicie o jogo e teste seu mod no mapa West Coast, USA!
